# Weather, blood flow and OCFormer additions

All six PNG animations are served from `public/data/animations/<name>/` as
`index.json` plus `frames.bin`. Names are weather, latent, swarm128, vortex, jet,
and blood. The binary concatenates unchanged PNG bytes; each image has an
`offset`, `length`, and SHA-256 in the index. Blood retains eight synchronized
panels per snapshot. Timing, labels, provenance, and metrics remain in the index.
The browser validates the bundle and frame hashes before decoding PNG blobs.

Experiment inputs stay in `data/raw/` or their recorded external source paths;
export intermediates stay in ignored `data/staging/`. Exporters publish bundles
through `scripts/animation_bundle.py`. Static/print fallback images remain in
`public/fallback_figures/` and blood's existing figure directory. No source
experiments or image rendering were rerun for this storage migration.

## Latent/optimized physical paths — slide 38 (formerly 32)

Eight colors, hollow initial positions, faint paths, square panels and reciprocal
phi arrows preserve the original style. The original hand-designed detour is
superseded: physical positions are all 200 unmodified saved q frames from
`room_2d/OCFormer_-1_16/best_pred_lbfgs.h5`, the exact file loaded by the paper's
`room_2d/analysis.ipynb`. The left straight reference interpolates its recorded
endpoints, as in that notebook. The near-antipodal endpoints cross centrally
(numerical boundary tolerance applies). Time spans the source 0–10 s grid.
The right paths are numerically optimized L-BFGS results, not a certified global
optimum or proof of a diffeomorphism. Source run and plotting notebook are hashed.

## 128-drone 2D example — slide 43 (formerly 37)

The 2D tab is first and selected by default; the existing 3D inspector remains available. All 200 frames
come from `room_2d/OCFormer_0_256_M=128/best_pred_lbfgs.h5`. The collector checks
the 128-agent endpoint arrays. Time uses the source 200-point 0–10 s grid.
Native positions use the paper's `pub-path-time.ipynb` style: hollow radius-0.01
circles, 128 hex colors generated by `default_rng(5)`, and cumulative gray
trajectory histories with alpha=0.1. Histories extend only up to the current
drone position; future trajectories are not drawn. Pairwise
clearance is minimum distance minus 0.02, using the source radius 0.01. Its
sampled minimum is 0.0002346057; this is not a continuous-time safety certificate
or an amortized-inference result. No obstacle is added to this empty-room case.

## Weather — slide 34

Static station geometry accompanies two stacked temperature maps (reference
and reconstructed) from saved RFormer
`case2/run-001` predictions: 59 measured observations and 1961 query stations.
The source uses daily mean temperature in Celsius, with 2020–2023 training and
366 sequential 2024 test days. We display all 366 recorded days, with actual calendar labels. Source preprocessing
fills missing station days; this is disclosed, not newly imputed by the viewer.
Reference values are recovered from paired `case2_weather/processed/valid.h5`
only after exact checks of all observation/query coordinates and observed values.

Both smooth maps use identical spatial display processing, not gridded ground truth: linear station
interpolation on a 650×300 longitude/latitude grid, then normalized Gaussian
smoothing at sigma=1.2 pixels. It is masked to Natural Earth US land and the
station convex hull. No temperature is invented beyond station coverage; white
areas remain unavailable. Saved reference data contain extreme outliers, so
both panels use a fixed -40 to 45 °C display range; out-of-range station counts
are labeled per frame. Original values remain unchanged, their full range is
retained in metadata, and no extra source quality control is claimed. No
temporal frames are synthesized. Local geographic boundary input is hashed.

## Blood — slide 35

The previous movie is replaced by the original published `blood_snapshot_u.pdf`
and `blood_snapshot_v.pdf`, converted to PNG without changing their panels or
color scales. Each is 2×2: sparse observations, raw/full target, RFormer
reconstruction, averaged-grid reference. The distinction between raw and
averaged references remains explicit. `docs/blood_snapshot_sources.json`
records source/output paths and hashes. Historical movie assets remain on disk
but are no longer displayed or regenerated. Published aggregate near-tie metrics
remain qualified; static snapshots do not imply a large accuracy advantage.
